# NeRF Mesh Denoising

An OpenGL/C++ program for refining and smoothing meshes reconstructed from MobileNeRF. This tool processes 3D meshes that exhibit a grid-like surface structure, exploring face refinement methods that account for manifold properties and mesh connectivity.

## Features

- ✅ **Mesh Rendering** - Interactive 3D visualization with camera controls
- 🔄 **Auto Mesh Cleanup** - Automatic removal of problematic geometry (in progress)
- ✅ **Manual Mesh Cleanup** - Boundary and non-manifold face removal
- 📋 **Smoothing** - Surface smoothing algorithms (planned)
